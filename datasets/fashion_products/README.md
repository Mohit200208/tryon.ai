# Fashion Product Images dataset

Download the Kaggle **Fashion Product Images** dataset and place its `styles.csv` here:

`datasets/fashion_products/styles.csv`

If the downloaded archive includes an `images/` directory, place it here:

`datasets/fashion_products/images/`

Common dataset source:
https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-dataset

The recommender supports common columns such as `productDisplayName`, `articleType`,
`baseColour`, `usage`, and `id`. The commonly shared dataset may not include retail prices;
in that case budget filtering cannot be accurate and unknown prices are retained.

Do not commit a large dataset to GitHub unless its license and repository size are suitable.
