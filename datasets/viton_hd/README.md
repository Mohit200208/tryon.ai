# VITON-HD dataset setup

VITON-HD is intended for research on high-resolution virtual try-on. Follow the official
repository instructions and dataset terms before downloading or using it:

https://github.com/shadow2496/VITON-HD

Keep the downloaded files in this folder if following a compatible training/inference setup.
This starter project does **not** train VITON-HD or load its model weights automatically.
A model server/inference endpoint must be started separately and configured using
`TRYON_API_URL` in `.env`. Check the repository's license and dataset terms before use.
